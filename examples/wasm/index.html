Absolute → WebAssembly

Loads Absolute wasm built with absolutec --target wasm32-unknown-unknown --build-exe. The integration board lives at examples/integration/webapp.abs.

main — UI thread, HTTP/TCP mocks only (no Atomics.wait).
worker — session Worker; can use nested WebSocket TCP when the page is cross-origin isolated (COOP/COEP). Prefer node scripts/serve-wasm-demo.mjs.

Optional globals: __ABSOLUTE_HTTP_MOCKS, __ABSOLUTE_TCP_MOCKS, __ABSOLUTE_WS_MAP ({"host:port":"ws://…"}). 

Drop or choose a .wasm file (smoke, managed, http, net, …).
